# PlayStation -1

PlayStation -1 is a keyboard-first command-line arcade for people who enjoy quick, self-contained games without leaving the terminal. It is designed for short breaks: start a game with one command, play for as long as you like, and return to the menu when you are done.

## MVP

Version 1.0 provides a terminal menu and a data-driven game catalogue featuring the **calculator** game. Players can view help and game information, launch the game, solve randomly generated arithmetic problems, receive immediate feedback, and see a session summary when they quit. All interaction is through the keyboard, and scores last for the current session only.
