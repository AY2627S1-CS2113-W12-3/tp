# PlayStation -1

PlayStation -1 is a keyboard-first command-line arcade for people who enjoy quick, self-contained games without leaving the terminal. It is designed for short breaks: start a game with one command, play for as long as you like, and return to the menu when you are done.

## Project summary

PlayStation -1 is a terminal arcade with six games: **Wordle**,
**Calculator**, **Battleship**, **Tic Tac Toe**, **GTA -6**, and **Snake**.
Players can view help and game information, start a game from the menu, earn
points for selected achievements, and keep their total points between
application runs.
