# Lim Zi Jing's Project Portfolio Page

## Overview

PlayStation -1 is a command-line collection of short games for people who want a quick break without leaving the terminal. Players can start Wordle, Calculator, Battleship, or Tic Tac Toe, then return to the menu when they finish.

## Summary of Contributions

- **Persistent points:** Added a local points store and the `score` command, then connected rewards to correct Calculator answers and wins in Wordle, Battleship, and Tic Tac Toe. The points remain available after the app closes. This feature connects game results, shared command handling, and file storage; I added tests for the store, command, and reward flows.
