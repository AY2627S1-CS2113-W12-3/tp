# Yue Wei An Joshua's Project Portfolio Page

## Overview
### Project: PlayStation -1

PlayStation -1 is a Java command-line application featuring five mini-games: Wordle, Calculator, Battleship, Tic Tac Toe, and GTA -6. 
It provides users with quick entertainment through a single terminal interface, allowing them to enjoy quick breaks.

## Summary of Contributions

* **New Feature: Battleship game.**
    * **What it does:** 
      * Allows players to compete against a computer opponent in a turn-based Battleship game. Players attack coordinates on a 7 × 7 board to locate and sink four enemy ships before the computer sinks theirs.
    * **Justification:** 
      * Introduces a strategy-based game to PlayStation -1, offering a different gameplay experience from the other mini-games and increasing the variety of games available to users.
  * **Highlights:**
    * Game design separates game logic, board management and ship tracking into distinct classes.
    * Implemented random ship placement while preventing overlaps and out-of-bounds placements.
    * Designed the computer's attack mechanism using shuffled coordinates to ensure distinct random attacks.
